Corepass Next: Windows application on Rust + Tauri 2 with a Russian interface, Naive HTTPS profiles, subscription import, system proxy and TUN modes, authenticated local API, persistent redacted logs, and process/proxy recovery.

OpenWrt: Rust rpcd controller and LuCI UI, selected-device routing by MAC, official sing-box 1.14.3 in a compact read-only SquashFS image. Installer targets OpenWrt 24.10 / mediatek-filogic / ARM64 and installs disabled. Active Steer or another routing controller blocks activation; Corepass does not stop it or overwrite its configuration.

Windows unit/build checks and native ARM64 configuration/image checks run in GitHub Actions before publishing. The exact Cudy router has not yet been tested; no hardware throughput or compatibility guarantee is made. Start with one test device.

See README for one-command router installation and third-party licensing. Personal profiles and credentials are never included.
